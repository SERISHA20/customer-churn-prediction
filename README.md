# Customer Churn Prediction

## Project Description
This project predicts whether a customer is likely to leave a company using machine learning/deep learning techniques.

## Features
- Customer data input
- Churn prediction
- Simple user interface using Streamlit
- Prediction result displayed to the user

## Technologies Used
- Python
- TensorFlow
- Pandas
- NumPy
- Scikit-learn
- Streamlit
